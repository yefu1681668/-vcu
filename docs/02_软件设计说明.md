# VCU 软件设计说明（SDD）

版本 v1.2 | 与需求规格 SRS v1.2 对应

## 1. 软件架构

```
                   ┌──────────────────────────────────────┐
 CAN 接收 (10ms)  → │ Signal_Conditioning  信号调理/范围检查 │
 (BMS/MCU/TCU)     └──────────────┬───────────────────────┘
                                  ▼
                   ┌──────────────────────────────────────┐
                   │ Fault_Management  故障诊断/等级判定    │
                   │ 通信超时 · SOC · 温度 · 预充失败         │
                   └──────────────┬───────────────────────┘
                                  ▼
                   ┌──────────────────────────────────────┐
                   │ State_Machine (Stateflow)             │
                   │ INIT→PRECHARGE→READY→DRIVING/REGEN    │
                   │          →FAULT→SHUTDOWN              │
                   └──────────────┬───────────────────────┘
                                  ▼
                   ┌──────────────────────────────────────┐
                   │ Torque_Control  扭矩计算/限幅           │
                   │ Lookup Table · 模式系数 · 故障降额       │
                   └──────────────┬───────────────────────┘
                                  ▼
                  CAN 发送 (10ms): VCU_Status / TorqueCmd
```

## 2. 模块设计

### 2.1 Signal_Conditioning
- 对 AccelPedal / BrakePedal 做 0–100% 限幅，越界钳位并置诊断位
- 对 SOC 做 0–100% 限幅
- 对 GearReq 做枚举合法性检查，非法值按 N 挡处理

### 2.2 Fault_Management
- 通信监控：维护 BMS/MCU 接收计数器，> 500 ms 置位故障码 bit0/bit1
- SOC 低：带 5% 迟滞（< 15% 锁存，> 20% 恢复），置 bit3
- MCU 过温：置 bit2，降额
- 预充失败：置 bit4，STOP
- 故障等级取所有已激活故障的最高级别

### 2.3 State_Machine（Stateflow 核心）
状态定义与迁移条件详见 `model/images/state_machine.svg`。

关键设计点：
- **预充消抖**：母线电压达标需连续保持 100 ms（10 个任务周期），避免抖动误判
- **预充超时**：5 s 未完成判失败，防止硬件故障时永久卡在 PRECHARGE
- **故障优先级**：STOP 级故障覆盖一切状态，立即进 FAULT
- **恢复路径**：通信恢复后不直接回 DRIVING，而是回 INIT 重新走预充握手

### 2.4 Torque_Control
- 踏板 MAP（Lookup Table）：
  - 0% → 0 Nm
  - 10% → 0 Nm（死区）
  - 50% → 540 Nm（45% × 1200）
  - 100% → 1200 Nm
- 模式系数：ECO 0.7 / NORMAL 1.0 / SPORT 1.15
- 故障降额：LIMIT_TORQUE × 0.5，STOP → 0
- 输出限幅：[TorqueLimitMin, TorqueLimitMax]

## 3. 任务调度

| 任务 | 周期 | 优先级 | 内容 |
|---|---|---|---|
| 10 ms 周期任务 | 10 ms | 高 | 状态机 + 扭矩控制 + VCU_Status/TorqueCmd 发送 |
| 100 ms 周期任务 | 100 ms | 中 | 故障诊断 + VCU_Fault 发送 |
| 1 s 后台任务 | 1 s | 低 | 故障日志记录 |

## 4. 标定参数

| 参数 | 值 | 说明 |
|---|---|---|
| PRECHARGE_RATIO | 0.95 | 预充完成电压比 |
| PRECHARGE_HOLD_MS | 100 | 预充保持时间 |
| COMM_TIMEOUT_MS | 500 | 通信超时阈值 |
| SOC_LOW_THRESHOLD | 15% | 低 SOC 限扭阈值 |
| SOC_RECOVER_THRESHOLD | 20% | 迟滞恢复阈值 |
| SOC_REGEN_DISABLE | 95% | 禁止回收阈值 |
| TORQUE_MAX_D | 1200 Nm | D 挡最大扭矩 |
| REGEN_MAX | 300 Nm | 最大回收扭矩 |

## 5. 模型与代码一致性

- `src/vcu_core.py` 是可执行规格（MIL 参考）
- `model/build_model.m` 生成 Simulink 模型骨架
- `model/images/state_machine.svg` 是 Stateflow 状态图
- 三者状态定义、参数、迁移条件完全一致，通过 `test/test_vcu.py` 的 14 个用例验证
